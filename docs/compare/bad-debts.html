貸倒損失・貸倒引当金・償却債権取立益の違い

貸倒引当金は将来の貸倒れに備える勘定、貸倒損失は引当金で足りない貸倒れなどの損、償却債権取立益は前の期までに貸倒れにした債権を回収できたときの収益です。

表で比べる

観点貸倒損失貸倒引当金償却債権取立益
何を表すか貸し倒れた損将来の貸倒れへの備え前の期までに貸倒れにした債権を回収できたもうけ
分類費用売掛金などから差し引く勘定（評価勘定）収益
使う場面当期に発生した売掛金が貸し倒れたとき、または引当金で足りないとき決算で見積もって設定する。前の期の売掛金が貸し倒れたら取り崩す前の期までに貸倒れとして処理した債権を、今期に回収したとき
仕訳の例（貸倒損失）20,000 ／（売掛金）20,000（貸倒引当金）20,000 ／（売掛金）20,000（現金）10,000 ／（償却債権取立益）10,000

見分けるポイント

  • 前の期の売掛金が貸し倒れたら、まず貸倒引当金を取り崩し、足りない分は貸倒損失
  • 当期に発生した売掛金が貸し倒れたら、引当金は使わず全額を貸倒損失
  • 前の期に貸倒れにした分を回収したら償却債権取立益（今期に貸倒れにした分の回収なら、貸倒れの仕訳を取り消す）

試験での出され方

「前期に発生した売掛金が貸し倒れた。貸倒引当金の残高は〇〇円である」のように、引当金の残高と貸倒れの金額を比べて仕訳を書かせる問題が定番です。売掛金が当期のものか前の期のものかを、必ず確かめましょう。

それぞれの用語

  • 貸倒損失

    その期に発生した売掛金などが貸し倒れたときや、貸倒引当金で足りないときの損。

  • 貸倒引当金

    期末の売掛金などのうち、次の期以降に貸し倒れそうな金額を見積もって準備しておく勘定。売掛金などから差し引いて見る。

  • 償却債権取立益

    前の期までに貸し倒れとして処理した売掛金などを、今期になって回収できたときの収益。
