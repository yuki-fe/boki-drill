先入先出法と移動平均法の違い

どちらも商品有高帳で払い出す単価を決める方法です。先入先出法は先に仕入れたものから払い出したと考え、移動平均法は仕入れるたびに平均の単価を計算し直します。

表で比べる

観点先入先出法移動平均法
考え方先に仕入れた商品から先に払い出す残っている分と新しく仕入れた分を平均した単価で払い出す
単価の計算仕入れた単価ごとに分けて書く仕入れるたびに（残高の金額＋仕入の金額）÷（残高の数量＋仕入の数量）
例: 10個@100円の後に10個@120円を仕入れ、15個を払い出す10個×100円＋5個×120円＝1,600円平均の単価110円×15個＝1,650円

見分けるポイント

  • 先入先出法では、単価の違う商品を分けて、2行にして書くことがある
  • 移動平均法では、仕入れたときだけ単価が変わる。払い出しでは単価は変わらない
  • 商品有高帳は原価で書く。売値（売上の金額）は書かない

試験での出され方

商品有高帳を完成させて、払出の金額・月末の残高・売上原価・売上総利益を求める問題が出ます。どちらの方法で書くかは問題文で指示されるので、表の書き方を両方練習しておきましょう。

それぞれの用語

  • 先入先出法

    先に仕入れた商品から先に払い出したと考えて、払い出す単価を決める方法。

  • 移動平均法

    商品を仕入れるたびに、残っている分と合わせた平均の単価を計算し直して、払い出す単価にする方法。
