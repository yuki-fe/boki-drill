似た用語の違い簿記3級・2級でまぎらわしい用語 15組

簿記では、名前の似た勘定科目や、似た手続きの違いがよく問われます。2つ（3つ）の用語を表で並べて、どこが違うか・仕訳がどう変わるかを確かめましょう。

  • 前払費用と未払費用の違い

    前払費用は「先に払った、次の期の分の費用」で資産、未払費用は「サービスは受けたのに、まだ払っていない費用」で負債です。どちらも決算で使う経過勘定です。

  • 前受収益と未収収益の違い

    前受収益は「先に受け取った、次の期の分の収益」で負債、未収収益は「サービスは提供したのに、まだ受け取っていない収益」で資産です。どちらも決算で使う経過勘定です。

  • 売掛金と未収入金の違い

    どちらも「あとで代金を受け取る権利」ですが、商品を売ったときは売掛金、商品以外のもの（使わなくなった備品など）を売ったときは未収入金を使います。

  • 買掛金と未払金の違い

    どちらも「あとで代金を支払う義務」ですが、商品を仕入れたときは買掛金、商品以外のもの（備品や車など）を買ったときは未払金を使います。

  • 仮払金と立替金の違い

    仮払金は「自分の会社の支払いだが、内容や金額がまだはっきりしない」ときの勘定、立替金は「本来は他人が払うべきお金を、代わりに払った」ときの勘定です。

  • 前払金と前受金の違い

    商品の受け渡しの前に代金の一部（手付金・内金）をやりとりしたとき、払った側は前払金（資産）、受け取った側は前受金（負債）を使います。

  • 仮払消費税・仮受消費税・未払消費税の違い

    税抜方式では、仕入などで払った消費税を仮払消費税（資産）、売上などで受け取った消費税を仮受消費税（負債）に記録し、決算でその差額を未払消費税（負債）にします。

  • 貸倒損失・貸倒引当金・償却債権取立益の違い

    貸倒引当金は将来の貸倒れに備える勘定、貸倒損失は引当金で足りない貸倒れなどの損、償却債権取立益は前の期までに貸倒れにした債権を回収できたときの収益です。

  • 貸借対照表と損益計算書の違い

    貸借対照表（B/S）は期末の「財産の状態」、損益計算書（P/L）は1年間の「もうけ」を表す表です。どちらも決算で作る財務諸表です。

  • 普通預金と当座預金の違い

    普通預金はいつでも出し入れでき利息が付く預金、当座預金は主に支払い（決済）に使う利息の付かない預金です。当座預金は、契約を結べば残高を超えて支払いができます（当座借越）。

  • 三分法と売上原価対立法の違い

    三分法は仕入・売上・繰越商品の3つの勘定で記録し、決算でまとめて売上原価を計算します。売上原価対立法は、商品を売るたびに売上原価を記録します。

  • 先入先出法と移動平均法の違い

    どちらも商品有高帳で払い出す単価を決める方法です。先入先出法は先に仕入れたものから払い出したと考え、移動平均法は仕入れるたびに平均の単価を計算し直します。

  • 定額法と定率法の違い

    定額法は毎期同じ金額を減価償却し、定率法は帳簿の金額に毎期同じ率を掛けるので、はじめの年ほど減価償却費が大きくなります。

  • 売買目的有価証券・満期保有目的債券・その他有価証券の違い

    有価証券は持つ目的で分けます。売買目的は時価に評価替えして差額を損益に、満期保有目的は時価に評価替えせず、その他有価証券は時価に評価替えして差額を純資産の部に記録します。

  • 個別原価計算と総合原価計算の違い

    個別原価計算は注文を受けて1つずつ作る製品の原価を製品ごとに計算し、総合原価計算は同じ製品を続けてたくさん作るときに、期間の原価をまとめて計算して1個あたりの原価を出します。
