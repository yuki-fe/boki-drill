学習する

できること

単語帳とクイズ300語をカード・4択・書いて答えるで。間違えた用語だけを復習できます。学習を始める →ミニテスト3級・2級の8つの分野から20問。分野ごとの正答率がわかる。挑戦する →勘定科目資産・負債・純資産・収益・費用のどれ？117科目の分類クイズ。覚える →用語タイピング用語と意味を打って、手で覚えます。制限時間は30〜180秒から。タイピングする →用語一覧分野・小分類ごとに全部の用語を一覧で。1語ずつ解説ページがあります。一覧を見る →

簿記用語ドリルについて簿記3級・2級の勘定科目と用語を無料で覚える単語帳（2027年4月からの範囲に対応）

簿記検定3級・2級に出てくる勘定科目と用語を、300語収録しています。3級の簿記の基本から、現金・預金、商品の売買、固定資産、税金、決算まで。2級の有価証券・収益認識・リース・税効果会計・連結会計と、工業簿記（原価計算）まで。はじめて簿記を学ぶ人にも分かるように、やさしい言葉で説明しています。登録は不要で、スマホでもパソコンでも無料で使えます。

学び方

カード
意味を読んで用語を思い出し、裏返して確かめます。「用語 → 意味」の向きにも切り替えられます。
4択クイズ
ア〜エの選択肢から答えを選びます。同じ分野の、まぎらわしい用語がひっかけとして並びます。
書いて答える
説明を読んで、用語を自分で入力します。「法人税、住民税及び事業税（法人税等）」なら「法人税等」でも正解になります。
復習
「まだ」を押した用語や、クイズで間違えた用語だけを集めて、学習し直せます。
ミニテスト
3級・2級の8つの分野から20問を出します。分野ごとの正答率がわかります。
勘定科目の分類
勘定科目が資産・負債・純資産・収益・費用のどれに入るか、増えたら借方か貸方かを覚えます。
用語タイピング
制限時間（30〜180秒）の中で、用語と意味の要点を打って覚えます。読みを見て打つ「練習」と、意味だけを見て用語を思い出して打つ「腕だめし」があります。

試験の範囲

試験の範囲は、実施団体の「出題区分表」で級ごとに決められています。このサイトでは、3級を6つの分野、2級を「2級 商業簿記」と「2級 工業簿記」の2つの分野に分けています。3級は60分で、2級は90分です。どちらも70%以上の得点で合格です。テストセンターで受けるネット試験と、決まった日に受ける統一試験があります。

2027年4月からの試験では、紙の手形・小切手の廃止と、新しいリースの会計基準にあわせて出題区分表が改定されます。「手形」が範囲から外れ、有形固定資産の除却・定率法などが2級から3級に移ります。2級のリースは「使用権資産」「リース負債」を使う形になります。このサイトは2027年4月からの範囲にもとづいています。2027年3月までに受ける人のために、手形の用語も「手形（2027年3月まで）」にまとめて残しています。

  • 簿記の基本31語
  • 現金・債権・債務37語
  • 商品売買20語
  • 固定資産・税金・純資産34語
  • 収益と費用22語
  • 決算25語
  • 2級 商業簿記78語
  • 2級 工業簿記53語

すべての用語は用語一覧から、1語ずつ解説ページで読めます。
