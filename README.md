# 簿記用語ドリル

簿記検定3級の勘定科目と用語を覚える静的サイトです。`python build.py` を実行すると `docs/` に全ページが書き出され、そのまま GitHub Pages で公開できます。

- 公開URL（予定）: https://boki.yogo-drill.com/

## フォルダの中身

| パス | 内容 | 編集するか |
|---|---|---|
| `config.json` | サイト名・公開URL・姉妹サイト・運営者・アクセス解析・広告の設定 | する |
| `data/make_terms.py` | 用語の元データ。実行すると `data/terms.json` を作る | する |
| `data/terms.json` | 用語データ（`make_terms.py` が作る） | しない |
| `build.py` | ページを生成するスクリプト。分野（`FIELDS`）、ミニテストの問題数（`TEST_COUNTS`）、文面もここにある | 文面を変えるとき |
| `static/assets/` | CSS と JavaScript。`app.js` ホームの単語帳、`drill.js` ミニテストと勘定科目の分類クイズ、`term.js` 用語ページの確認問題 | 見た目や機能を変えるとき |
| `docs/` | 生成されたサイト。**直接編集しない** | しない |

## 普段の作業

```powershell
cd "C:\Users\admin\Desktop\boki-drill"
python data/make_terms.py             # 用語を直したとき
python build.py                       # docs/ を作り直す
python -m http.server 8000 -d docs    # http://localhost:8000 で確認（Ctrl+C で終了）
```

## 用語を追加・修正する

`data/make_terms.py` の `TERMS` に、`(分野, 小分類, 用語, 勘定の分類, 説明)` の形で書きます。

- 分野は `K`（簿記の基本）/ `A`（現金・債権・債務）/ `G`（商品売買）/ `F`（固定資産・税金・純資産）/ `P`（収益と費用）/ `C`（決算）
- 勘定の分類は `資産`・`負債`・`純資産`・`収益`・`費用` のどれか。書くと「勘定科目の分類クイズ」に入る。勘定科目でない用語は `""`
- id は並び順で付く。**公開後は、新しい用語をリストの最後に足す**
- 範囲は、実施団体の出題区分表・勘定科目表（2027年4月1日施行の版）の3級に合わせる

## 名前について

「日商簿記」は実施団体の名前を含むので、サイトの名前には入れていません。全ページの下に、実施団体とは関係がないことの注意書きを出しています。
